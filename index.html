SOC COMMAND CENTER

Nexus-SuperApp (Ultimate Edition)

Platform: Windows (10/11) • Mimari: Portable (Kurulum Gerektirmez) • Şifreleme: Yerel SQLite Kasası

GitHub Deposu ve Kodlar ↗

Siber Güvenlik Uzmanları, Sistem Denetçileri (Auditor) ve Olay Müdahale (Incident Response) ekipleri için Python ile sıfırdan geliştirilmiş hepsi bir arada "Siber Savunma ve Adli Bilişim" aracıdır.

1. Otonom Firewall & Ağ Keşfi (Recon)

Zararlı IP adreslerini tespit ederek Windows Güvenlik Duvarı'na tek tıkla engelleme (Block) kuralı yazar. Hedef IP istihbaratı, Port taraması, ARP tablosu okuma ve aktif TCP (Netstat) bağlantı analizi gerçekleştirir.

2. OSINT & Web Sniper

Hedef domainlerde gizli dizin, subdomain ve HTTP Header analizi yapar. E-posta MX kayıtlarını ve web teknoloji altyapısını (Tech Stack) ifşa eder. Zafiyet avcıları için Google Dork üretir.

3. Zafiyet Denetimi (Auditor)

Windows Event Loglarına sızarak başarısız RDP (Uzak Masaüstü) kaba kuvvet saldırılarını tespit eder. Başlangıç (Autorun) zararlılarını ve yerel yönetici (Admin) yetkilerini denetler.

4. Dijital Adli Bilişim (Forensics)

Windows Kayıt Defteri (Registry) üzerinden geçmiş USB bağlantılarını, sistem açılış kayıtlarını ve kritik adli kanıtları ayıklayarak yerel şifrelenmiş SQLite kasasında saklar.
